**Bug real de rate limit en el `Convert Resume Poller` encontrado y corregido (18 ago 2026):** medición empírica confirmó que el límite real de la API de JazzHR (`/job/{jobId}/projob`) es ~1 request exitosa cada 10-11 segundos — 20 veces más estricto que el `batchInterval` de 600ms que tenía el Poller.
